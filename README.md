# MNIST Digit Classifier

A simple web application built with Flask that uses a neural network trained on the MNIST dataset to recognize handwritten digits.

## Screenshot

![image alt](https://github.com/AnsarAshirbekov/MNIST_Image_Generator/blob/27f3d4ab32ad9dcecbf831fd13f8323b63178991/digit.png)

## Features

- Flask backend
- PyTorch neural network
- MNIST handwritten digit recognition
- Simple web interface

## Technologies

- Python
- Flask
- PyTorch
- HTML/CSS
